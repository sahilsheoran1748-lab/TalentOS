# TalentOS — Workforce Intelligence Platform

TalentOS is an interactive workforce intelligence demonstration
built with Python, Streamlit, Pandas and Plotly.

## Features

- Executive workforce overview
- Employee intelligence
- Recruitment intelligence
- Financial intelligence
- ROI calculator
- Hiring simulator
- Data Trust Centre
- Integration and Migration Centre
- Cold-Start Onboarding Wizard
- Action Intelligence Centre

## Run locally

Install dependencies:

    pip install -r requirements.txt

Launch the application:

    streamlit run app.py

## Data and limitations

This demonstration uses fictional synthetic datasets.
It is not production HR software and must not be used to
process confidential employee information.

Recommendations and financial calculations are illustrative
and require human review.
